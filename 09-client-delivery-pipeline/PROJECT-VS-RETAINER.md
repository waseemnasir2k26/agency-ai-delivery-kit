# Project or retainer?

Not automatically a retainer. Decide by the shape of the work.

|                       | PROJECT                                                                                             | RETAINER                                                                                                                                            |
| --------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Shape                 | Has a start, a delivery and a support period                                                        | Repeats on a schedule                                                                                                                               |
| Kiran Studio example  | The Sufi Threads winter collection page                                                             | Monthly Site Watch checks on the client's pages                                                                                                     |
| What the client signs | The proposal + the service boundary sheet (deliverables, review window, support period, exclusions) | A smaller recurring agreement: what runs, how often, what each run reports, who to call                                                             |
| How it is priced      | Full cost of delivery for one job (`pricing-worksheet.md`), then margin                             | Full cost of delivery per period: the repeating job's measured run cost (Episode 6 cost report) plus review time, support and overhead, then margin |
| What ends it          | The support period closes                                                                           | Either side gives notice                                                                                                                            |

## The rule

- Sell a one-off page as a **project**.
- If the client then wants the page watched every month, that is a **second, smaller agreement**, not a reason to
  turn the first job into a retainer.
- Before you fix either price, measure a few runs. One run is one run.
