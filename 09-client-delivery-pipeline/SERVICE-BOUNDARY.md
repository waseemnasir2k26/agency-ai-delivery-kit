# Service boundary sheet

A pipeline is not a service until its edges are written down. Six rows. They go into the proposal, before the
client signs. Cells marked EXAMPLE CELL are yours to set: this sheet carries no numbers and no prices.

## Kiran Studio example (fictional Sufi Threads winter page)

| Row                  | What goes here                                                                                | Example                                                                                                 |
| -------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **DELIVERABLES**     | What the client receives                                                                      | One collection page, on a preview and then live. The QA evidence. One approved report.                  |
| **CLIENT PROVIDES**  | What the client must give before the build                                                    | Prices, photos, fitting hours, where enquiries go, and one named person who can approve.                |
| **REVIEW WINDOW**    | How long the client has to ask for changes after the preview, and what happens when it closes | \_\_\_\_ (you set this) · EXAMPLE CELL                                                                  |
| **SUPPORT INCLUDED** | For a stated period, what gets fixed                                                          | For \_\_\_\_ (you set this · EXAMPLE CELL), we fix anything that fails the checks listed in the report. |
| **EXCLUSIONS**       | What is not part of this job                                                                  | No promise on rankings or sales. No new features. No changes inside the client's other systems.         |
| **WHO TO CALL**      | One named person at the agency, not a shared inbox                                            | Owner, Kiran Studio · +92 300 0000000 (placeholder)                                                     |

**Disputes:** if the client disputes a line in the report, open the evidence link for that line (page, quoted
text, screenshot). That is what the links are for.
