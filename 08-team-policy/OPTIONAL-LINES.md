# Optional lines — OFF by default, UNTESTED

None of these lines is in `managed-settings.template*.json`, and none was tested on the build. They come from the settings documentation. If you add one, test it on a lab machine, add a `policy_test.py` line for it, and record the decision in `POLICY-OWNER.md`.

| Line                                                          | What it is for                                                                                                                                                  | Why it is off here                                                                                                                          |
| :------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------ |
| `"allowManagedHooksOnly": true`                               | Only hooks from managed settings (and approved plugins, per the docs) run; user and project hooks are ignored. Stops a client repo from bringing its own hooks. | It may also switch off hooks your team relies on. Check that `kiran-core`'s secret-firewall and commit-gate still fire before you trust it. |
| `"availableModels": [ … ]` + `"enforceAvailableModels": true` | Limits which models a seat may pick. A managed `model` alone is only a default; this pair is the lock.                                                          | Model choice is a cost and quality decision, not a data rule. Add it when you have a reason (e.g. a client contract).                       |
| `"syncClaudeAiPlugins": false`                                | Stops plugins and connectors from a person's claude.ai account syncing into Claude Code on the seat.                                                            | Kiran Studio seats did not use claude.ai connectors. If yours do, decide per connector.                                                     |
| `"permissions": { "denyInsteadOfPrompting": true }`           | Calls that would prompt are denied instead of asking a person.                                                                                                  | It removes the "ask a person" answer the policy is built on (`git push` would always be refused). Useful on unattended machines only.       |

Exact key names and placement can change between releases: confirm each one against https://code.claude.com/docs/en/settings-reference before use.
