# client-report checks (pass/fail, graded by tests/run-checks.py)

1. WINS: the report has a section headed "Wins" with exactly 3 bullet lines (- or 1.).
2. NO EMAIL: no email address anywhere in the report.
3. NUMBERS: site visits, leads and revenue from the data file appear exactly as in the data (thousands commas allowed), and no other figure >= 10 appears that is not in the data file.
4. LENGTH: 150 words or fewer.
